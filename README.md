# Сайт приложения Pathway

Одностраничник: что такое Pathway, как работает, возможности, экраны, скачивание APK и политика конфиденциальности.

Адрес: https://pretwora.github.io/pathway-web/

Стиль — дизайн-система приложения ([`E:\Projects\Pathway`](../Pathway), `docs/02-дизайн-система.md`): тёмная тема, палитра «Фирменная» из логотипа, Unbounded + Manrope, без теней. Логотип на первом экране собирается той же анимацией, что заставка в приложении.

## Структура

- `index.html`, `privacy.html`, `assets/` — сайт (чистый статик, без сборки)
- `downloads/` — APK приложения
- `tools/make-images.py` — логотип, фавиконки, фон плитки и превью ссылки (`og.png`) из исходников приложения
- `tools/sync-logo.mjs` — геометрия логотипа для анимации из `../Pathway/src/ui/logo-geometry.ts` → `assets/js/logo-data.js`

## Локальный запуск

```bash
npx serve -l 4174 .
```

## Новая версия приложения

1. Положить подписанный APK в `downloads/` (`pathway-<версия>.apk`), старый удалить.
2. Поправить версию, размер и SHA-256 в `index.html` (первый экран и блок «Скачать»), ссылки на файл.
3. Поднять `?v=` у `style.css` и `main.js`, если менялись, — против кэша Pages.

## Деплой

GitHub Pages, ветка `main`, корень репозитория. Пуш в `main` → автопубликация.
